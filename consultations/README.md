# Consultations

Alliance responses to regulator calls for evidence and public consultations.

Responses are drafted in the open and reviewed by members before submission. A response in this directory carries its own status notice — **a draft here is not submitted, agreed, or endorsed by DAIAA until that notice says so.**

## How to comment

Open the pull request for the response and leave inline comments on the lines you are responding to. Anyone with a GitHub account can comment; you do not need to be a repository collaborator.
